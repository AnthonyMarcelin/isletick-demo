# isletick-demo

Dépôt de démonstration pour [Isletick](https://isletick.app), l'app macOS qui affiche vos pull requests, vos workflows GitHub Actions et le chrono de vos clients dans la Dynamic Island du MacBook Pro.

Ce dépôt sert à l'équipe de vérification de l'App Store et aux essais : il contient une pull request ouverte et un workflow qui tourne toutes les quatre heures, avec un échec volontaire de temps en temps pour montrer les différents états dans l'app.

Il ne contient aucun code utile.
